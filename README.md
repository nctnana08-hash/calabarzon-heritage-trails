# CALABARZON Heritage Trails

Virtual Tour and Cultural Mapping App (Phase 1) for Region IV-A (CALABARZON) as an alternative to educational field trips.

Build as a mobile-first web app / PWA with Lovable Cloud enabled.

Objectives and Requirements:
1. Destination Management (CRUD):
   - Add, view, edit, and delete destination records.
2. Destination Information:
   - Display destination name, description, address/province (Cavite, Laguna, Batangas, Rizal, Quezon), category, and image.
3. Search and Filtering:
   - Search destinations and filter by category (e.g., Historical Shrines, Religious Landmarks, Museums, Natural Heritage) and province.
4. Navigation:
   - Mobile navigation between home discovery screen, destination list / cultural map, and destination details.
5. Database Integration:
   - Use Lovable Cloud (PostgreSQL database and storage) to store and retrieve destination records and images, pre-seeded with iconic CALABARZON heritage sites.

Reference styling / aesthetic: https://nmfa.nationalmuseum.gov.ph/ (clean, elegant cultural museum aesthetic).
